Créer un jeu

Votre enfant a une passion. Faites-en un jeu.

Pas besoin de savoir coder : une IA écrit le code avec vous. Comptez une soirée pour un premier jeu, quelques soirées pour qu'il soit bien. Voici le chemin, de l'idée jusqu'à Ludiworld.

  • Une idée née de votre enfant
  • Une IA Claude, ChatGPT…
  • Une soirée pour commencer

  1. 1

    Partir de votre enfant

    Ce qu'il adore (les dragons, les fusées, les cochons) et ce qu'il doit apprendre (les tables, lire l'heure, l'ordre des inventions). Le meilleur jeu marie les deux. Pluie de Cochons est né comme ça : des tables de multiplication, et des cochons qui tombent du ciel.

    Écrivez trois phrases : pour qui, ce qu'il apprend, comment on gagne. Et prévoyez une fin : une partie courte, qui se termine vraiment.

  2. 2

    Choisir son IA

    Pour commencer sans rien installer : Claude ou ChatGPT, dans le navigateur. On écrit ce qu'on veut, l'IA fabrique le jeu dans une page qu'on essaie tout de suite.

    Pour aller plus loin, des outils comme Claude Code ou Cursor travaillent dans les fichiers de votre ordinateur : plus puissants, un peu plus techniques. Les versions gratuites suffisent souvent pour un premier essai ; pour un jeu plus riche, un abonnement aide.

  3. 3

    Le premier jet

    Décrivez le jeu comme à un ami développeur. Par exemple :

    Puis corrigez au fil de l'eau, en mots simples : « les boutons sont trop petits », « c'est trop dur au début », « ajoute un dragon qui fait la fête quand il gagne ».

  4. 4

    Tester avec lui

    Regardez-le jouer sans l'aider. Ce qu'il ne comprend pas, ce qui l'ennuie, ce qui le fait rire : tout est bon à prendre. Demandez-vous surtout : est-ce qu'il apprend vraiment, ou est-ce qu'il clique au hasard ?

    Apprendre doit rester fun. Si c'est un exercice déguisé, il le sentira tout de suite.

  5. 5

    Le rendre compatible Ludiworld

    Donnez le guide à votre IA. Il lui explique tout : vérifier que le jeu respecte la charte, écrire sa fiche honnête (l'âge, ce qu'on y apprend, la durée d'une partie), et si vous voulez, ajouter le petit kit qui envoie les scores à Ludiworld.

    Si votre IA ne sait pas ouvrir les liens, ouvrez le guide vous-même et copiez-lui son contenu.

  6. 6

    Le publier, gratuitement

    Ludiworld n'héberge pas les jeux : chacun garde le sien chez lui. Le plus simple est GitHub Pages, gratuit. Créez un compte sur github.com, et laissez votre IA vous guider clic par clic : créer un dépôt, y déposer les fichiers du jeu, activer Pages. Quelques minutes après, le jeu a son adresse, du genre https://votre-nom.github.io/votre-jeu/.

    Honnêtement : c'est l'étape la plus technique. Une façon de proposer un jeu sans GitHub est prévue plus tard.

  7. 7

    Le proposer

    Collez l'adresse du jeu dans le formulaire. Un robot vérifie la fiche et vous répond en une minute. Ensuite Julien joue au jeu, la fiche sous les yeux. Si tout est juste, le jeu entre dans Ludiworld, et des enfants que vous ne connaissez pas apprendront avec.

Ce qui sera refusé, même dans un super jeu

  • La pub, même discrète.
  • Quelque chose à acheter, ou un abonnement.
  • Les récompenses tirées au hasard.
  • « Reviens demain », les séries à ne pas perdre, les notifications.
  • Parler à des inconnus.
  • Envoyer des données sur l'enfant, où que ce soit.
  • Une partie sans fin, sans moment où s'arrêter.

Les questions qu'on se pose

Combien ça coûte ?

Ludiworld et GitHub Pages : rien. L'IA : gratuite pour essayer, payante si vous y passez du temps.

Mon jeu reste à moi ?

Oui. Il est publié chez vous, sous votre nom. Ludiworld garde seulement une copie de sa fiche. Vous pouvez le modifier ou le retirer quand vous voulez.

Et si mon jeu apprend peu ?

Il a sa place. La fiche le dit simplement : « pour le plaisir ». Ce qui compte, c'est qu'il soit sain et qu'il dise la vérité.

Mes enfants jouent sur ma tablette. Et leurs données ?

Rien ne quitte l'appareil : Ludiworld garde les réglages et le temps de jeu dans le navigateur, et les jeux s'engagent à ne rien envoyer. Le jeu ne reçoit que le pseudo de l'enfant.

Je n'ai pas le temps de faire un jeu, mais je veux aider.
