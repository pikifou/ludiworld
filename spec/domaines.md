# Vocabulaire des domaines d'apprentissage

Utilisé dans les fiches (`learning.domains`) et par `Ludi.skill`. Format `famille.notion`, en minuscules, mots anglais ou français sans accents, séparés par des tirets. On ajoute une notion quand un jeu en a besoin ; on évite les doublons.

| Domaine | Notion |
|---|---|
| `maths.multiplication` | Tables de multiplication |
| `maths.calcul-mental` | Calcul mental en général |
| `sciences.magnetisme` | Aimants, pôles, matériaux attirés, électroaimant |
| `sciences.physique` | Forces, poids, mouvement |
| `histoire.prehistoire` | Âge de pierre, néolithique |
| `histoire.techniques` | Inventions et leur ordre (feu, outils, agriculture…) |
| `logique.puzzle` | Résoudre un problème en plusieurs étapes |
| `memoire.sequences` | Retenir et reproduire une suite |
| `gestion.ressources` | Produire, dépenser, prévoir |
| `motricite.reflexes` | Réflexes, précision, esquive |
| `strategie.choix` | Choisir entre des options et en voir les effets |

Pistes à venir : `histoire.egypte`, `histoire.grece`, `mythologie.grecque`.
